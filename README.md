# Chocoberry

Site vitrine responsive pour une marque de cookies artisanaux.

## Lancer le site

Ouvre `index.html` dans ton navigateur, ou installe l'extension VS Code **Live Server** puis clique sur **Go Live**.

## Publier sur GitHub depuis VS Code

1. Ouvre ce dossier dans VS Code.
2. Clique sur l'icône **Source Control** dans la barre latérale.
3. Clique sur **Publish Branch** ou **Publish to GitHub**.
4. Connecte ton compte GitHub si VS Code le demande.
5. Choisis si le dépôt doit être public ou privé.

Les réglages du projet activent le Smart Commit et synchronisent automatiquement après chaque commit. Une fois le dépôt publié, tes prochains commits effectués depuis VS Code seront donc directement poussés vers GitHub.
